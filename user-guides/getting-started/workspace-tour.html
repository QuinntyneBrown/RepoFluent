Tour of the workspace

RepoFluent looks like a code editor on purpose. The frame around your content never moves, so you always know where you are. This page names every part of it, tells you which parts are interactive, and — just as usefully — tells you which parts are only scenery.

Getting around: the activity bar

The narrow icon rail down the left edge is the whole of RepoFluent's navigation. It has four destinations. The current one is marked with a green edge.

Destination What is there Who it is for
Curricula The governed content pipeline: upload, validation evidence, review, publication, assignment, comparison, retirement, and audit history. This is the page you land on. Author, Reviewer, Administrator, Auditor
Learning Your assigned learning, and the way in to courses, lessons, and source context. Learner only
Systems A map of an example system with a filter, a node inspector, and an accessible relationship table. Anyone
Quality The performance budgets and the published browser support policy this instance is measured against. Anyone
Two pages have no link

The curriculum contract and the authoring kit are fully working pages that are not in the activity bar. You reach them by typing the address: add /contracts or /authoring-kit to your instance URL. Both are worth bookmarking if you author content — see The curriculum contract and The authoring kit.

On a narrow window

Below roughly a tablet width the workspace explorer disappears entirely, and on a phone-sized window the activity bar moves to the bottom of the screen and the status bar is hidden. The banner and header stay pinned in both cases.

What is scenery, and why

RepoFluent's frame is a finished visual design wrapped around a partly built product. Several parts of it look interactive and are not. Knowing which is which will save you real time.

Looks like Actually is
Command search (Ctrl K) A working dialog around a search that has not been built. It opens, traps focus correctly, closes on Esc, and returns focus to the button — but typing produces no results and it always shows Start typing to search the current workspace.
Workspace explorer tree A fixed illustration. The entries (workspace.rf, curriculum.lifecycle, learning.dashboard, and so on) name the product's capabilities but do not navigate anywhere.
Tab strip and breadcrumbs Fixed text. They always read workspace.rf and repofluent › governed-learning › workspace.rf regardless of the page you are on.
Sync pill The literal word synced. It is not monitoring anything.
Status bar Four fixed labels. 0 errors is not a live count.

Everything else in the frame — the persona menu, the activity bar, the skip link — works exactly as it appears to.

The parts built for keyboards and screen readers

Three behaviors in the frame are easy to miss but make the product much faster to use.

Skip to content
Press Tab as soon as the page loads and a Skip to content link appears in the top-left corner. Following it jumps straight past the banner, header, and navigation into the page itself.
Page change announcements
Every time you navigate, RepoFluent moves keyboard focus to the new page's main heading and announces <Heading> page loaded to assistive technology. You do not have to hunt for where you landed.
Pinned chrome
The banner and header stay at the top of the window while content scrolls beneath them, and scrolling to an anchor accounts for their height so the target is never hidden behind them.

The full keyboard and preference reference is on Accessibility and preferences.
