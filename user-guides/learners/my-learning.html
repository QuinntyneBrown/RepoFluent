My learning

My learning is where a learner starts. It answers one question — what should I work on now — and gets you into a course in a single press.

  • Learner
RF-UG-06

Getting there

Set the Development persona menu to Learner, then choose Learning in the activity bar on the left. The page heading is My learning.

You must be the Learner persona

Opening this page as Author, Reviewer, Administrator, or Auditor shows a red Learning dashboard unavailable message. That is not a fault — learning is deliberately restricted to learners. Switch persona and the page loads.

The four things this page can show you

What you see What it means
Loading assigned learning… Placeholder shapes while your assignments are fetched. This should be brief.
Learning dashboard unavailable Either you are not the Learner persona, or the API could not be reached. The message underneath names which.
No learning assigned You are a learner, the page works, and nobody has assigned you anything yet. An administrator has to publish a version and assign it to you.
Ready when you are, Maya The populated dashboard. One card per assignment, plus a status rail and a queue table.

Reading an assignment card

Each assignment is one card. Everything on it comes from the published curriculum, so the wording is the author's, not the product's.

Assignment cardannotated
1 Recommended_next 2 Required
3 Assigned course / Not started 4 Order Processing Foundations 5 Why this is next → Begin with the intake boundary 6 Start course ↵
  1. Recommended_next. A fixed label on every card, not a ranking.
  2. Required or Optional. Set by the administrator when the work was assigned to you. Required work is expected; optional work is enrichment.
  3. Assigned course / Not started. A fixed label. See the limitation below — it does not update.
  4. Course title and description. From the published curriculum.
  5. Why this is next. The most useful line on the card: the author's own reason this course comes at this point.
  6. Start course. Opens the course. This is the only interactive control on the card.

Below the card you will also see a line like $ course start order-processing-foundations. That is styling, not a command you can run — it shows the course's stable identifier, which is occasionally useful when reporting a problem.

About the progress figures

Preview limitation — progress is not tracked

RepoFluent does not yet record what you have read or completed. Every progress indicator on this page is a fixed placeholder: Session progress 0%, the ring reading 0 complete, Course progress 0, the status Ready to begin, Not started, and the queued pill in the table. They will not change however much you read, and they are not reported to anyone.

Two figures on the page are real, because they are simple counts:

  • Assigned queue — how many assignments you have.
  • The line reading N active assignments — the same count in words.

This also means you cannot lose your place by closing the browser, because there is no place being saved. Use the course outline to find where you were.

The queue table

At the bottom of the page is a compact table of the same assignments, useful when you have several. Its columns are:

Type
Always Course in this release.
Next action
The same author-written reason shown as Why this is next on the card.
Priority
REQ for required, OPTIONAL otherwise. This is real and comes from your assignment.
Status
Always queued. A placeholder, as described above.

What happens when you press Start course

You move to the course page, which shows the outcomes you should be able to demonstrate, the estimated time, and the full outline of modules and lessons. That is the subject of the next page.

If a course you were using stops opening, the version it belonged to may have been retired. Retirement keeps existing assignments working, so this is unusual — see Troubleshooting.
