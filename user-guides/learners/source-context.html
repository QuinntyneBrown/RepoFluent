Reading source context

This is the feature RepoFluent exists for: moving from an explanation to the exact code it describes, at the exact revision it described, without leaving the lesson.

  • Learner
  • Reviewer
RF-UG-08

Opening it

Inside a lesson, a code reference block looks like a pressable row: a symbol name in bold, a line range and language underneath, and an open badge on the right. Its accessible name is Open source context for <symbol> — for example Open source context for OrderController.Create.

Press it, and one of two things happens depending on your screen.

WIDE SCREENsplit

The lesson narrows and the source appears beside it. You can read the explanation and the code at the same time, which is the point.

NARROW SCREENdrawer

The source slides in over the lesson as a drawer. Your scroll position in the lesson is kept, so closing it returns you exactly where you were.

Either way, keyboard focus moves into the source panel so you can read it immediately, and the code reference you pressed stays marked as the active one.

What the panel tells you

The panel is headed Source context and has five parts, top to bottom.

  1. Language and symbol — for example csharp · OrderController.Create — with the close control.
  2. The path, repository-relative, such as src/Order.Api/Controllers/OrderController.cs. It is never an author's local absolute path.
  3. Source location — the branch and commit the excerpt was taken from, the line range, the language, and the content classification.
  4. The excerpt itself, read-only, starting at the line number shown.
  5. Provenance · verified — a green note stating where this evidence came from and what it is being used to explain.

Why the commit matters

The excerpt is bound to a specific revision. It is what the code looked like when the curriculum was generated, not what it looks like on your branch right now. That is a feature: the explanation and the code you are reading always agree with each other.

Check the commit before you act on it

If the branch and commit shown are old, the file may have moved or changed since. Use the excerpt to understand the design, then look at the current file in your own tools. Keeping content fresh is the authors' job, and it is why versions get compared and retired — see Comparing versions.

Read-only, and only what was supplied

You cannot edit code here, and you are not browsing a repository. You are seeing the specific excerpt the curriculum package supplied, with its classification recorded. RepoFluent deliberately stores the minimum amount of source needed for the lesson to make sense.

Closing it

There are two ways, and they behave slightly differently on purpose.

The close control
The × button labelled Close source context. Focus returns to the code reference you pressed, so you carry on reading from the same spot.
The browser Back button
Opening source context adds an entry to your browser history, so Back closes the panel rather than leaving the lesson. This is what most people reach for, and it works.

The address bar changes, and that is useful

While the panel is open the address gains a ?source= parameter identifying which reference is open. That means you can copy the address and send it to a colleague, and they will open the same lesson with the same source excerpt already showing. Bookmarking it works the same way.

Fully keyboard operable

Every code reference is a real button, focus moves into the panel when it opens and back to the reference when it closes, and Esc or Back will get you out. Nothing here requires a pointer.

Code tours: several references in order

A code tour block is a numbered walk through one behavior across several files. Each step shows its own guidance, repository and path, and branch, commit, symbol, and line range, so a tour is readable straight through without opening anything.

Tours keep your course context: you are still inside the lesson, moving down a list, rather than being sent off to a separate viewer. If a tour has a companion code reference block, use that to see the excerpt for a particular step.

What is not here

  • No file tree and no repository browser. You see referenced excerpts, not whole repositories.
  • No links out to a hosted repository provider. RepoFluent does not connect to one in this release.
  • No search across code. The Ctrl K command search in the header does not search anything yet.
  • No syntax colouring guarantees beyond what the excerpt supplies; the excerpt is presented faithfully and read-only.
