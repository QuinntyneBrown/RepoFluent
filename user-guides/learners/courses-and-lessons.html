Courses and lessons

A course is an ordered set of modules; a module is an ordered set of lessons; a lesson is an ordered set of blocks. Everything is deliberately linear, so there is always an obvious next thing to read.

The course page

Pressing Start course brings you here. The page has four parts.

Header
A ← My learning link back to your dashboard, an assigned pill confirming this course really is assigned to you, and the course's difficulty and estimated minutes.
Title and description
The author's summary of what the course covers.
Course outcomes
A checklist of the objectives you should be able to demonstrate when you finish. These are the units RepoFluent is designed to report against, so they are worth reading before you start rather than after.
Course outline
Every module, and inside each module the numbered lessons with their individual estimated minutes. Each lesson title is a link. This outline is your position marker — since progress is not saved, note where you stopped.

If the page shows Course unavailable, either the course is not assigned to you or the version has been withdrawn. See Troubleshooting.

The lesson page

A lesson opens with its estimated reading time, its title, and a By the end, you can panel listing the specific objectives this lesson serves. Then comes the body: a sequence of blocks.

Preview limitation — the Rendered / Source toggle

At the top of every lesson there is a pair of controls reading Rendered and Source, and a source verified pill. The toggle is decorative — it is not a button and pressing it does nothing. There is no raw-source view of a lesson in this release. To see the code behind an explanation, use a code reference block instead, described on Reading source context.

The eight kinds of lesson block

RepoFluent renders a fixed, allow-listed set of block types. Nothing else is permitted — a package cannot introduce arbitrary markup, scripts, or remote content, which is why lessons are safe to read even though they were generated by an agent.

Block Looks like What to do with it
Prose A plain paragraph. Read it. This is the bulk of a lesson.
Callout An indented aside with a bold title and an ↳ mark. Something the author thought you would otherwise miss. Worth slowing down for.
Diagram A chain of labelled nodes with a described badge and a caption. Read the caption — it carries the meaning. The diagram is decorative and has a hidden text alternative for screen readers, so nothing is lost if you cannot see it.
Code reference A pressable row showing a symbol name, a line range, and a language, with an open badge. Press it to open the actual source. See Reading source context.
Code tour A numbered list of steps, each with guidance, a repository and path, and a branch, commit, symbol, and line range. Follow the steps in order. A tour walks one behavior across several files, which is the fastest way to understand a flow.
Example A titled section of worked explanation. A concrete case for the concept just described.
Glossary link A term and its definition, inline. Definitions come to you rather than making you leave the lesson to look them up.
Knowledge check A boxed question mark, a prompt, and a line reading Assessment · <identifier>. Read the prompt and answer it in your head — see the limitation below.
Preview limitation — you cannot answer a knowledge check

Knowledge-check blocks display the question and the identifier of the assessment it belongs to, and nothing more. There are no answer options, no submit control, no scoring, and no feedback. Quizzes and tests are fully modelled in the curriculum package and validated on upload, but the interface for taking one has not been built. Nothing you do in a lesson is scored or recorded.

If a block cannot be shown

Occasionally you may see a red box reading Unsupported lesson block with the support code LEX-BLOCK-UNSUPPORTED. It means the package used a block type this version of RepoFluent does not render. The rest of the lesson is unaffected. Quote that code and the lesson title when you report it.

Long lessons reveal themselves in batches

A lesson with more than ten blocks does not render all at once — this keeps very long lessons fast to open. You will see a footer reading Showing 10 of 33 lesson blocks and a button reading Show 10 more lesson blocks.

  • Each press reveals up to ten more blocks. The final press reveals however many remain and the button disappears.
  • Keyboard focus moves to the first newly revealed block, so you continue reading from exactly the right place instead of being dropped back at the top.
  • The count is announced to assistive technology as it changes.
Use the browser's own find

Because hidden blocks are genuinely not on the page, your browser's find-in-page will not match text you have not revealed yet. If you are searching for something specific in a long lesson, reveal everything first.
